# mdwriter

Минималистичный редактор Markdown в духе Obsidian. Написан на **100% Rust**
(GUI — egui/eframe, без webview). Офлайн, без облака и телеметрии:
заметки — это обычные `.md`-файлы в папке-«vault».

## Возможности

- **Vault** — работа с папкой `.md`-файлов, слежение за изменениями на диске
  (`notify`), атомарная запись: временный файл → `fsync` → `rename` (с
  повторами на Windows), поэтому обрыв посреди записи не оставляет
  «полузаметку»
- **Надёжность** — ошибки чтения и записи показываются уведомлениями, а не
  теряются в консоли; если файл открытой заметки изменили снаружи, правки не
  затираются: создаётся копия `имя (конфликт).md`, а удалённый файл не
  уничтожает буфер
- **Редактор** — подсветка синтаксиса Markdown (syntect), нумерация строк,
  автосохранение с дебаунсом (Ctrl+S — принудительно)
- **Живой предпросмотр** — собственный рендерер на pulldown-cmark:
  заголовки, таблицы, задачи-чекбоксы, цитаты, сноски, **callouts**
  (`> [!NOTE]` …), математика (placeholder-рендер `$...$`/`$$...$$`),
  подсветка кода в код-блоках
- **Связи заметок** — wikilinks `[[target|alias]]` кликабельны в
  предпросмотре (несуществующие создаются по клику), панель **backlinks**
- **Навигация** — быстрый переключатель **Ctrl+O**, полнотекстовый поиск
  по vault со сниппетами (совпадения в заголовке — выше, результаты
  кешируются)
- **Граф связей** — force-направленный layout (petgraph) с «остыванием»:
  раскладка затихает и перестаёт занимать процессор; клик по узлу открывает
  заметку
- **Ежедневные заметки** — кнопка «Today» создаёт `ГГГГ-ММ-ДД.md`
- **Экспорт в HTML** — открытой заметки в статический файл
- Тёмная/светлая тема

## Требования

| Платформа | Что нужно |
|---|---|
| Linux x86_64 | glibc ≥ 2.35, **OpenGL 2.0+**, X11 или Wayland |
| Windows x86_64 | Windows 10/11, **OpenGL 2.0+** |

Системные dev-пакеты для сборки не нужны: X11, Wayland и OpenGL подключаются
в рантайме.

**Ограничение:** запасного рендерера пока нет. На машине без OpenGL 2.0
(виртуальные машины без 3D-ускорения, часть RDP-сессий, очень старые
драйверы) приложение сразу завершается, причём в release-сборке сообщения не
видно — виноват `glow`/egui, которому нужен OpenGL 2.0+.

## Сборка и запуск

Требуется Rust **1.95+** (stable) и Cargo:

```bash
cargo build --release
cargo run
```

Бинарь: `target/release/mdwriter`.

- **Linux:** дополнительных dev-пакетов не нужно — X11, Wayland и OpenGL
  подключаются в рантайме.
- **Windows:** нужны Visual Studio Build Tools с компонентом «Разработка
  классических приложений на C++» (иначе `link.exe` не найден); сама сборка
  идёт через MSVC.

## Структура

```
crates/
├─ app/      # eframe-приложение, UI, горячие клавиши
├─ vault/    # файловое хранилище: обход, чтение/атомарная запись, слежение
├─ markdown/ # парсинг: frontmatter, wikilinks, теги
├─ index/    # индекс заметок: backlinks, разрешение ссылок, поиск
├─ preview/  # рендер Markdown в egui
└─ graph/    # граф связей + layout
```
