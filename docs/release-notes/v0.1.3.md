## mdwriter 0.1.3

Надёжность и скорость: заметки в новых папках снова замечаются, экспорт
больше не затирает файлы молча, а сохранение, поиск и граф не тормозят на
больших vault.

### Исправлено

- **Заметки в новых папках снова замечаются.** В 0.1.2 папки, созданные или
  перенесённые в vault после его открытия, не отслеживались: заметки в них не
  появлялись в дереве и поиске до переоткрытия vault. Теперь на Windows и
  macOS система следит за всем деревом сама, а на Linux новые папки ставятся
  на слежение по мере появления. Недоступные подпапки по-прежнему не мешают
  открыть vault.
- **Экспорт в HTML не перезаписывает файлы молча.** Если файл уже есть,
  появляется вопрос «Файл … уже существует. Заменить?», и ничего не пишется
  до подтверждения. Принимаются только имена `.html`/`.htm` (имя без
  расширения получает `.html`), поэтому экспорт под именем `заметка.md`
  больше не может заменить заметку. Файл записывается атомарно, как и
  заметки.
- **Уведомления больше не висят вечно.** Обычная ошибка сама исчезает через
  20 секунд, информационное сообщение — через 5. Ошибки-состояния («не
  удалось сохранить заметку») по-прежнему живут, пока проблема не решена.
- **Пустое имя заметки — не ошибка.** «+» или Enter с пустым полем ставят
  курсор в поле; сообщение «Имя заметки пустое» больше не появляется.

### Быстрее

- **Сохранение не подвешивает окно на больших vault.** Раньше после каждого
  автосохранения и каждой внешней правки весь vault перечитывался заново (на
  2000 заметках — около 0,9 с паузы). Теперь перечитываются только
  изменённые заметки (около 12 мс), поиск и обратные ссылки обновляются сразу
  после сохранения, а граф пересчитывается, только пока его окно открыто.
- **Окно графа не грузит процессор.** В 0.1.2 раскладка считалась
  бесконечно, пока окно открыто. Теперь она «остывает» и затихает примерно за
  120 кадров (около 2 секунд), после чего новые кадры не запрашиваются; после
  правки одной заметки граф лишь слегка подстраивается, а не раскладывается
  заново. На графе из 300+ заметок подписи рисуются только у открытой заметки
  и у узла под курсором.
- **Поиск по vault стал быстрее и точнее.** Нижний регистр текста хранится в
  индексе, а результаты кешируются до смены запроса или содержимого vault:
  на 2000 заметках (6–8 МБ текста) запрос занимает 1–2 мс, тогда как в 0.1.2
  поиск занимал десятки миллисекунд и повторялся в каждом кадре. Совпадения в
  заголовке показываются выше совпадений в тексте, а сниппет больше не
  «съезжает» в текстах с `İ` и знаком Кельвина `K`. Плата — около 9 МБ
  памяти на те же 2000 заметок.

### Скачать

| Платформа | Файл | Требования |
|---|---|---|
| Linux x86_64 | `mdwriter-0.1.3-linux-x86_64.tar.gz` | glibc ≥ 2.35, **OpenGL 2.0+**, X11 или Wayland |
| Windows x86_64 | `mdwriter-0.1.3-windows-x86_64.zip` | Windows 10/11, **OpenGL 2.0+** |

Контрольные суммы SHA256 — в `SHA256SUMS.txt`, рядом лежат отдельные `.sha256`.

```bash
tar -xzf mdwriter-0.1.3-linux-x86_64.tar.gz
cd mdwriter-0.1.3-linux-x86_64 && ./mdwriter
```

### Известные ограничения

- Без OpenGL 2.0 (виртуальные машины без 3D-ускорения, некоторые
  RDP-сессии, старые драйверы) приложение сразу закрывается — запасного
  рендерера (DirectX/Vulkan) пока нет.
- Поиск идёт и по frontmatter: запрос `tags` или `title` находит все заметки,
  где есть такой ключ.

### Обновление с 0.1.2

Достаточно заменить бинарник: формат заметок, настройки и структура vault не
менялись.

### Для разработчиков

- Библиотечные крейты переименованы в `mdwriter-*` и помечены
  `publish = false`; минимальная версия Rust — 1.95 (`rust-version`).
- Индекс собирает и инлайн-теги `#тег` вместе с тегами из frontmatter
  (`Index::notes_with_tag`); в интерфейсе панели тегов пока нет.
- Общий код отрисовки блоков в предпросмотре, настройки читаются один раз
  при запуске.
- `README.md` и `docs/PLAN.md` переписаны под текущее состояние приложения.
- CI проверяет fmt, clippy и тесты на Ubuntu и Windows; релизный workflow
  сверяет тег с версией из `Cargo.toml`.

### Сборка из исходников

```bash
cargo build --release -p mdwriter   # бинарь: target/release/mdwriter
cargo test --workspace
```
