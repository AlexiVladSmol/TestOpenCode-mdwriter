## mdwriter 0.1.0 — первый публичный релиз

Минималистичный редактор Markdown на Rust (egui/eframe): офлайн, без webview
и телеметрии. Заметки — обычные `.md`-файлы в папке-vault.

### Возможности

- **Vault** — обход папки, слежение за изменениями на диске, атомарная запись
  (правки не теряются при внезапном завершении).
- **Редактор** — подсветка синтаксиса Markdown, нумерация строк, автосохранение
  с дебаунсом, принудительное сохранение по `Ctrl+S`.
- **Живой предпросмотр** — заголовки, таблицы, списки-задачи, цитаты, сноски,
  callouts (`> [!NOTE]` …), подсветка кода в блоках.
- **Связи** — wikilinks `[[заметка|алиас]]` кликабельны в предпросмотре,
  несуществующие создаются по клику; панель backlinks.
- **Навигация** — быстрый переключатель заметок `Ctrl+O`, полнотекстовый поиск
  по vault со сниппетами.
- **Граф связей** — force-направленный layout, клик по узлу открывает заметку.
- **Ежедневные заметки** — кнопка «Today» создаёт `ГГГГ-ММ-ДД.md`.
- **Экспорт в HTML** открытой заметки, тёмная и светлая темы.

### Скачать

| Платформа | Файл | Требования |
|---|---|---|
| Linux x86_64 | `mdwriter-0.1.0-linux-x86_64.tar.gz` | glibc ≥ 2.35, OpenGL, X11 или Wayland |
| Windows x86_64 | `mdwriter-0.1.0-windows-x86_64.zip` | Windows 10/11 |

Контрольные суммы SHA256 — в `SHA256SUMS.txt`, рядом лежат отдельные `.sha256`.

Установка не требуется: распакуйте архив и запустите `mdwriter`
(`mdwriter.exe` на Windows). Бинарники не подписаны, поэтому Windows может
показать предупреждение SmartScreen, а на Linux потребуется разрешение на
запуск, если архив распакован с потерей прав.

```bash
tar -xzf mdwriter-0.1.0-linux-x86_64.tar.gz
cd mdwriter-0.1.0-linux-x86_64 && ./mdwriter
```

### Известные ограничения

- Дорожная карта (`docs/PLAN.md`): фазы 0–4 готовы, фаза 5 (полировка) —
  частично.
- Математика `$…$` и `$$…$$` пока рендерится заглушкой.
- Открытые дефекты и планы — `docs/FIX_PLAN.md`.

### Сборка из исходников

```bash
cargo build --release -p mdwriter   # бинарь: target/release/mdwriter
cargo test --workspace
```

Требуется Rust stable; системные dev-пакеты не нужны — X11, Wayland и OpenGL
подключаются в рантайме.
