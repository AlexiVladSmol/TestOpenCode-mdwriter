## mdwriter 0.1.2

Исправление: vault открывается, даже если внутри есть недоступные папки.

### Исправлено

- **Открытие домашней папки (`~`) больше не падает с «Permission denied».**
  Наблюдатель за файлами подписывался на все подпапки рекурсивно и
  обрывался на первой недоступной. В домашней папке это
  `~/.wine/dosdevices/z:` — симлинк внутрь `/tmp/systemd-private-…`, куда
  обычному пользователю входа нет, поэтому vault `~` не открывался вовсе.
- Слежение теперь ставится по папкам отдельно, с тем же фильтром скрытых
  папок (`.git`, `.cache`, `.wine`, …), что и обход заметок. Недоступные
  папки пропускаются, а вместо ошибки показывается одно информационное
  уведомление: «слежение недоступно для N папок» — изменения в них не
  подхватятся автоматически, остальное работает.
- Скрытый корень по-прежнему поддерживается: vault можно держать в
  `~/.notes`.
