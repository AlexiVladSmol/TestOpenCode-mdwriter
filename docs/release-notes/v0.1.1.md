## mdwriter 0.1.1

Точечный релиз: выбор папки больше не подвешивает окно.

### Исправлено

- **«Open vault…» не замораживает интерфейс.** Раньше системный диалог
  вызывался прямо в потоке отрисовки: окно переставало перерисовываться на всё
  время выбора, а под Linux диалог портала мог открыться позади окна
  (`Failed to associate portal window with parent window`), и приложение
  выглядело зависшим.
- **Выбор папки — собственное окно:** список подпапок (двойной клик — войти),
  кнопки «Вверх» и «Домой», поле пути с поддержкой `~` и относительных
  путей, переключатель показа скрытых папок. `Esc`, клик по фону и «Отмена»
  закрывают окно; пока оно открыто, глобальные горячие клавиши не срабатывают.
- **«Export HTML»** переведён на то же окно: выбираете папку и имя файла,
  расширение `.html` дописывается автоматически (`note` → `note.html`).

### Изменено

- Системный диалог (`rfd`) убран из зависимостей: xdg-desktop-portal и
  `libdbus` больше не нужны ни для сборки, ни для запуска.

### Скачать

| Платформа | Файл | Требования |
|---|---|---|
| Linux x86_64 | `mdwriter-0.1.1-linux-x86_64.tar.gz` | glibc ≥ 2.35, OpenGL, X11 или Wayland |
| Windows x86_64 | `mdwriter-0.1.1-windows-x86_64.zip` | Windows 10/11 |

Контрольные суммы SHA256 — в `SHA256SUMS.txt`, рядом лежат отдельные `.sha256`.

Установка не требуется: распакуйте архив и запустите `mdwriter`
(`mdwriter.exe` на Windows).

```bash
tar -xzf mdwriter-0.1.1-linux-x86_64.tar.gz
cd mdwriter-0.1.1-linux-x86_64 && ./mdwriter
```

### Обновление с 0.1.0

Достаточно заменить бинарник: формат заметок, настройки и структура vault не
менялись.

### Сборка из исходников

```bash
cargo build --release -p mdwriter   # бинарь: target/release/mdwriter
cargo test --workspace
```
