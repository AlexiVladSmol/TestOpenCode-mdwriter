# Черновик заметок к следующему релизу

Накопленные изменения живут в `main`, релиз выпускается по решению владельца
репозитория. Этот файл — рабочий черновик; в момент выпуска он
переименовывается в `docs/release-notes/v<версия>.md`, и workflow
`release.yml` берёт тело релиза именно оттуда (иначе падает на
`--generate-notes`). Образец готовых заметок — `v0.1.3.md`.

Правило простое: **каждая правка, которую стоит упомянуть в релизе, добавляет
пункт сюда же**, вместе с ID задачи из `FIX_PLAN.md`, если он есть.

## Скачать (шаблон — переносить в каждый релиз)

| Платформа | Файл | Требования |
|---|---|---|
| Linux x86_64 | `mdwriter-<версия>-linux-x86_64.tar.gz` | glibc ≥ 2.35, **OpenGL 2.0+**, X11 или Wayland |
| Windows x86_64 | `mdwriter-<версия>-windows-x86_64.zip` | Windows 10/11, **OpenGL 2.0+** |

**Известное ограничение (упоминать в каждом релизе):** без OpenGL 2.0
приложение сразу закрывается — запасного рендерера (DirectX/Vulkan) пока нет.
